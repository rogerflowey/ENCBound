# Original matched Juliet execution rows

These files are copied byte for byte from the October 11
`build/juliet/pilot-2026-10-11-adapters/` run in ENCBound-restart. They retain the
129-case matched selection, 774 raw execution rows, summary and original input
identities. Absolute paths and transcript references describe that historical
run. Its source snapshots, debugger logs, binaries and signing keys are not
included here. Use [the evaluation report](../../tests/juliet/EVALUATION.md) for
interpretation and [the recipe](../../tests/juliet/README.md) for a fresh run.

These are SDK simulation records. A normal bad-case return does not establish
containment or that the faulty access executed. Historical results remain
separate from any fresh packaging validation.
