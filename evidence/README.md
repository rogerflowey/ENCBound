# Selected original evidence

These dated narrative and JSON records are preserved byte for byte from the
research working tree. They describe their original configurations and runs.
Absolute paths, historical documentation links and binary hashes remain
historical references; excluded original build output is not packaged.

Fresh export-validation outcomes are recorded separately in ../VALIDATION.json.
The export does not relabel old records as new results. Native execution, SDK
SIM and SGX hardware are distinct, as are BASELINE, RADIX_ONLY and MAC27. A
build or unexplained crash alone is not protection evidence. No fresh SGX
hardware or performance result was produced during packaging.
